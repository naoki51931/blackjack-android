# Blackjack 21 Android

Offline Blackjack game built with Kotlin + Jetpack Compose.

## Features
- Hit / Stand
- Dealer draws to 17
- Ace automatically counts as 1 or 11
- Blackjack-style card table UI
- Card dealing animation
- Bust screen shake / red result
- Win counter
- Fully offline; no permissions or API required

## Build
Open the repository in Android Studio, use JDK 17, sync Gradle, then run the `app` configuration.

Package: `com.naoki51931.blackjack`
